# 芳华录：图集与视频

保留 dayv.org 的现有排版与“芳华录”标题，导航增加“图集 / 视频 / 关于”。图集继续读取已完成的采集照片组。视频栏目为横向封面卡片，支持最新、最早、24条分页；点击卡片进入可独立分享的 `/videos/<图床编码>` 播放页。

## 1. 更新镜像

先按[图库部署流程](dayv-gallery.md)在原帖边界暂停采集、备份，并将 SJC 的 `/opt/lsky/docker-compose.tg-import.yaml` 改为**包含本功能且 Actions 已成功的完整 SHA 镜像**，沿用原基础 Compose 与覆盖文件更新 `lsky-pro`。不要直接拉旧 SHA，不重装图床、不删除数据卷、不重置采集游标。

检查 `php artisan migrate:status` 中 `2026_10_18_130000_create_gallery_video_metadata` 已执行。它只新增视频时长、内容指纹、封面文件名表，不修改旧图片记录；未配置视频相册时，不会自动公开任何视频。现有照片相册、图库分组、TG API、归档与15GiB缓存设置保持原样。

## 2. 创建并明确公开视频相册

在 **dayv.io 图床账号**中新建独立相册，例如“频道视频”。将希望公开的视频上传到该相册；上传界面没有相册选择时，可以上传后在文件管理中移入。不要与“频道图片”使用同一相册。当前频道采集器仍只采集照片，不会因为增加栏目就自动搬运源频道视频。

确认内容可以公开后，在 SJC 执行以下**单行**命令（修改邮箱和实际相册名称）：

```bash
docker exec -u www-data -w /var/www/html lsky-pro php artisan gallery:configure --user=bigyvc@gmail.com --album='频道图片' --video-album='频道视频' --host=dayv.org --title='芳华录' --enable
```

**此操作公开所选账号、所选视频相册中的健康视频，即使原图床记录权限为私有。** 其他相册、其他账号、游客文件和音频不会进入视频栏目。照片仍按既有完整采集组展示，普通图片不会被自动猜组。

视频列表直接读取选定相册，不需要再次执行 `gallery:sync`。后续上传或移入的视频刷新后出现；移出、删除或标为异常后，从栏目和视频媒体路由退出。再次配置图库但未传 `--video-album` 时，同账号已配置的视频相册会保留。

## 3. 生成封面和时长

浏览器不会在访客请求时下载原视频来抽帧。先运行后台命令，每次最多处理20个尚未准备好的视频：

```bash
docker exec -u www-data -w /var/www/html lsky-pro php artisan gallery:videos --limit=20
```

只处理某个图床编码，或重新生成：

```bash
docker exec -u www-data -w /var/www/html lsky-pro php artisan gallery:videos --key=替换为图床编码 --force
```

命令从**该记录现有存储策略**读取一份临时文件，使用镜像自带 ffprobe/ffmpeg 生成JPEG封面与时长。只生成封面，不转码、不重新上传视频、不发送TG消息。一次一个，单文件不超过512MiB、视频尺寸不超过8192像素，复制前预留文件大小加2GiB磁盘；探测25秒、抽帧30秒超时。处理完成删除临时视频；任务被意外终止遗留的专用临时文件，会在下次取得独占锁后清理。

本地读取速度取决于TG缓存或其他存储线路；从TG读取可能使TG API缓存增加，继续由既有缓存清理机制管理。请在低负载时运行，不建议与大规模导入争抢资源。没有启动后台定时处理，上传新视频后需再次执行准备命令。

封面位于 `storage/app/gallery-video-posters` 私有目录，通过校验相册归属的路由输出，不放到静态公共目录。时长与封面指纹存SQLite，当前数据库备份会包含它们；JPEG封面可重新生成，现有配置备份不一定包含JPEG。没有封面时显示视频占位图，时长位置显示“视频”，仍可进入播放页。

## 4. 访问与播放

- 列表：`https://dayv.org/videos`
- 播放页：点击视频封面得到，不改变原图床链接。
- 列表和播放页初次打开仅加载封面，播放器 `preload=none`，不设置原视频src；点击“播放视频”才请求原文件。
- 原文件使用既有流式输出，支持 HEAD、Range；TG视频仍经SJC中转，缓存命中可减少重复从TG下载。主题不提供转码或自适应码率，视频本身越大，带宽开销越大。
- 优先上传 MP4（H.264＋AAC），通常兼容性较好；WebM、HEVC、MOV、MKV等是否能播放依赖浏览器和轨道编码。扩展名支持上传不等于所有浏览器都能播放。原始 `.hevc/.h265` 仍沿用原图床附件响应，不能保证网页直接播放。
- 本栏目暂不发布M3U8播放列表；HLS外部地址、分片目录、外部播放器依赖不在本次范围。
- 未加入额外下载按钮或防下载功能；能够播放的视频仍可能被浏览器或其他工具保存。

## 5. 关闭视频公开

保持图片栏目开启，仅撤销视频相册：

```bash
docker exec -u www-data -w /var/www/html lsky-pro php artisan gallery:configure --user=bigyvc@gmail.com --album='频道图片' --host=dayv.org --title='芳华录' --disable-videos --enable
```

视频列表显示空状态，原视频的图库播放页、封面和媒体路由返回404。撤销只影响图库公开范围，不删除图床记录或TG文件，也不能撤回别人已经保存或缓存的内容。

## 验收

检查旧图集仍正常，视频栏目分页正确；图片相册里的视频、其他账号/相册、游客文件不能从视频路由读取。打开列表与播放页时，浏览器网络面板不应出现 `/gallery-video-media/.../original`，点击播放后才出现。抽查拖动进度、手机全屏、编码不兼容提示和移出相册后404。

自动验证覆盖Laravel HTTP/数据库公开边界、真实本地视频抽帧、缺失封面、配置兼容、jsdom按需播放/错误/分页。手机及桌面实际画面、真实TG线路性能仍需上线后验收。
